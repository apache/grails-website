Package: org.grails.openapi

[Groovy] Interface ActionHooks

  • @CompileStatic
interface ActionHooks

    What a document decides by the action itself, and does to each operation it describes, where its selection implements it: springdoc's method filters and operation customizers, applied to the Grails actions. Internal to Grails; a selection is otherwise a plain set of criteria.
