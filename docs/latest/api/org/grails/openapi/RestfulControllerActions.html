Package: org.grails.openapi

[Groovy] Class RestfulControllerActions

    • org.grails.openapi.RestfulControllerActions 
    • @CompileStatic
class RestfulControllerActions
extends java.lang.Object

      The shape of the actions RestfulController declares, used to describe a controller reached through the default "/$controller/$action?/$id?" mapping rather than through a mapping that names it.

        • static boolean locates(java.lang.Class<?> controllerClass, java.lang.String actionName)

          Whether the action answers with where the resource it created or updated is, in the Location header. RestfulController's own save and update do, and its patch through update. A controller generated for a REST application does not, so an action the controller overrides, or declares itself, is not described with it.

        • static boolean paginates(java.lang.String actionName)

          Whether the action reads the paging and sorting parameters GORM binds from the query string. Only the listing does; the remaining actions address one resource.

        • static boolean refusedWhenReadOnly(java.lang.Class<?> controllerClass, java.lang.String actionName)

          Whether a RestfulController constructed read only refuses the action. RestfulController answers METHOD_NOT_ALLOWED from its write actions, so one the controller inherits is refused, while one it provides itself does whatever it provides.

        • static java.lang.String successCode(java.lang.String actionName)

          The status a successful action responds with. RestfulController answers CREATED from save and NO_CONTENT from delete rather than OK.

        • static boolean takesId(java.lang.String actionName)

        • static boolean validates(java.lang.String actionName)

          Whether the action validates what it binds, and so can answer with the validation errors. Patch delegates to update, so all three do.
