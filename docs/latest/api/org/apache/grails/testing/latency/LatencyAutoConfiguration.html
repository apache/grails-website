@org.springframework.boot.autoconfigure.condition.ConditionalOnProperty(prefix: grails.testing.latency, name: enabled, havingValue: true)
@org.springframework.boot.context.properties.EnableConfigurationProperties(value: LatencyProperties)
class LatencyAutoConfiguration
extends java.lang.Object

      Auto-configuration that registers the LatencyFilter when grails.testing.latency.enabled is true.

      The filter is registered with the highest precedence so that the configured delay applies to the entire request processing pipeline, mirroring what a slow network or server would look like to an HTTP client or browser driving the application under test.
