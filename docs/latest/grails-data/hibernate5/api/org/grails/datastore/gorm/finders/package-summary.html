Package org.grails.datastore.gorm.finders

  • Interface Summary 
    Interface Description
    FinderGrammar The composition seam finder implementations use to parse a dynamic finder method name into a DynamicFinderInvocation and build the resulting Query.Junction, without subclassing DynamicFinder.
    FinderMethod Implementation of dynamic finders.
    QueryBuildingFinder Implemented by finders that build queries.
  • Class Summary 
    Class Description
    CountFinder Implements countBy*.
    DynamicFinder Parses a dynamic finder method name into a DynamicFinderInvocation, builds the AND/OR junction of criteria for it, and exposes the shared argument-map/fetch/sort/detached-criteria handling used by every finder implementation.
    DynamicFinderInvocation Value object used to construct all the information necessary to invoke a dynamic finder.
    FinderSupport Shared session-execution helper for the synchronous finder implementations in this package.
    ListOrderByFinder The "listOrderBy*" static persistent method.
    ListResultFinder Implements every dynamic finder that returns a list of results: findAllBy* and the findAll<booleanProperty>By* boolean-clause form - configured via static factory methods rather than subclassed, composing a DynamicFinder grammar instead of extending it.
    MatchSpec A match spec details a matched finder

    SingleResultFinder Implements every dynamic finder that returns a single result: findBy*, the find<booleanProperty>By* boolean-clause form, findOrCreateBy* and findOrSaveBy* - configured via static factory methods rather than subclassed, composing a DynamicFinder grammar instead of extending it.
