Package liquibase.ext.hibernate.diff

  • Class Summary 
    Class Description
    HibernateChangedColumnChangeGenerator Hibernate and database types tend to look different even though they are not.
    HibernateChangedForeignKeyChangeGenerator Hibernate doesn't know about all the variations that occur with foreign keys but just whether the FK exists or not.
    HibernateChangedPrimaryKeyChangeGenerator Hibernate doesn't know about all the variations that occur with primary keys, especially backing index stuff.
    HibernateChangedSequenceChangeGenerator Hibernate manages sequences only by the name, startValue and incrementBy fields.
    HibernateChangedUniqueConstraintChangeGenerator Unique attribute for unique constraints backing index can have different values dependending on the database implementation, so we suppress all unique constraint changes based on unique constraints.
    HibernateMissingSequenceChangeGenerator
    HibernateUnexpectedIndexChangeGenerator Indexes tend to be added in the database that don't correspond to what is in Hibernate, so we suppress all dropIndex changes based on indexes defined in the database but not in hibernate.
