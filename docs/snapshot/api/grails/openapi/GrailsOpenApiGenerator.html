Package: grails.openapi

[Groovy] Class GrailsOpenApiGenerator

    • grails.openapi.GrailsOpenApiGenerator 
    • @CompileStatic
class GrailsOpenApiGenerator
extends java.lang.Object

      Generates an OpenAPI description of a Grails application from its URL mappings, its controllers and its GORM mapping context.

      The generator depends on nothing but the application, so the same description is produced at build time by the generate-open-api command and at runtime by springdoc, which this module contributes the description to when springdoc is on the classpath.

      8.0
