Package: grails.openapi

[Groovy] Class OpenApiSettings

    • grails.openapi.OpenApiSettings 
    • @CompileStatic
class OpenApiSettings
extends java.lang.Object

      How the OpenAPI document is generated, read from the grails.openapi configuration.

      The same settings drive a document generated at build time and one springdoc serves. Where springdoc is present, its springdoc.paths-to-match, springdoc.paths-to-exclude, springdoc.packages-to-scan and springdoc.packages-to-exclude are honored for the default document as well, as are springdoc.produces-to-match, springdoc.consumes-to-match and springdoc.headers-to-match, and springdoc.api-docs.version chooses the OpenAPI version.

      Since:
      8.0
