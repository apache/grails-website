Package: grails.rest.render.errors

[Java] Class ValidationProblemDetailFactory

    • grails.rest.render.errors.ValidationProblemDetailFactory 
    • public final class ValidationProblemDetailFactory
extends java.lang.Object

      Creates an RFC 9457 problem detail from Spring validation errors.

      Rejected field values are omitted by default because they may contain secrets or other sensitive request data. Applications can explicitly include them by using ValidationProblemDetailFactory(boolean, MessageSource), which resolves the messages through the application's MessageSource.
