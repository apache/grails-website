          Parameters:
          jsonMapper - supplies the mapper each configuration derives from, resolved when a writer is first needed. Deferring it means the registry can be created before Jackson auto-configuration has produced Spring Boot's mapper, and still derive from that mapper rather than from a separately configured one. The first successful resolution is cached; a missing mapper is retried on the next write.

        • public void writeValue(java.lang.String name, java.io.Writer output, java.lang.Object value, java.util.List<java.lang.String> includes, java.util.List<java.lang.String> excludes)

          Writes with a per-response include/exclude projection applied on top of the named configuration. The projection applies to objects of the value's type, or of its elements' types when the value is a collection or array, unlike the legacy converter, which projects only the objects of the class of the value written: domain objects and beans Jackson writes property by property. A value with no properties to project, such as a map or a string, is rejected before anything is written. The writer is left open and unflushed, as writeValue(String, Writer, Object) leaves it.

          throws:
          IOException if the writer fails, with the exception Jackson reports the failure in suppressed
          throws:
          JacksonException if the value cannot be written otherwise, such as by a serializer that fails
          throws:
          IllegalArgumentException if no configuration of the name is registered, or if a projection is requested for a value it cannot apply to
          Parameters:
          name - the registered configuration, or null for the default one
          output - the response writer
          value - the value to write
          includes - property names to include, or null for all; an empty list includes none
          excludes - property names to exclude, or null for none
