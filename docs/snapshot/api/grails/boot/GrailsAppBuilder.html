Package: grails.boot

[Groovy] Class GrailsAppBuilder

      • grails.boot.GrailsAppBuilder 
      • @CompileStatic
class GrailsAppBuilder
extends SpringApplicationBuilder

        Fluent API for constructing and running a GrailsApp: the Grails counterpart of Spring Boot's SpringApplicationBuilder.

        Every builder method of SpringApplicationBuilder is available and keeps returning a GrailsAppBuilder, so a chain stays in Grails terms from start to finish and the application it runs is a GrailsApp with the Grails startup defaults:

        
 new GrailsAppBuilder(Application)
         .profiles('metrics')
         .properties('server.port=8081')
         .run(args)

        Parent/child context hierarchies work as they do in Spring Boot, with every context of the hierarchy started by a GrailsApp: child(Class[]), parent(Class[]) and sibling(Class[]) return Grails builders, a parent cannot host an embedded web server, and closing the parent closes its children. Exactly one context of a hierarchy is the Grails application, the one whose sources include the Grails application class; the others are plain Spring contexts that share the Grails beans through the parent chain. Because the parent cannot serve web requests, the application class belongs in the child of a two-level hierarchy:

        
 new GrailsAppBuilder(SharedConfiguration)
         .child(Application)
         .run(args)

          • @java.lang.Override
            GrailsAppBuilder child(java.lang.Class<?>[] sources)

            Creates a child of this builder whose context has the context this builder creates as its parent, as SpringApplicationBuilder.child does, except that the child is a GrailsAppBuilder running a GrailsApp. The default properties, environment and additional profiles configured so far are copied to the child.

            As in Spring Boot, a parent cannot host an embedded web server, because the servlets could not be initialized at the right point of the child's lifecycle: this builder is switched to WebApplicationType.NONE and its banner is turned off. The Grails application class therefore belongs in the child when the application serves web requests.

            Parameters:
            sources - the sources of the child context
            Returns:
            the child builder
