Package: grails.plugin.springsecurity.acl

[Groovy] Class AclService

    • grails.plugin.springsecurity.acl.AclService
    • All Implemented Interfaces and Traits:
      MutableAclService, WarnErros
      @CompileStatic
@Slf4j
class AclService
extends java.lang.Object
implements MutableAclService, WarnErros

      GORM implementation of AclService and MutableAclService. Ported from JdbcAclService and JdbcMutableAclService. Individual methods are

      Transactional:
      since NotFoundException is a runtime exception and will cause an unwanted transaction rollback

      Burt Beckwith
