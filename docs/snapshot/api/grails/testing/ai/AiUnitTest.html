Package: grails.testing.ai

[Groovy] Trait AiUnitTest

      • grails.testing.ai.AiUnitTest 
      • @Trait
@CompileStatic
trait AiUnitTest
extends GrailsUnitTest

        A unit test of code that uses Spring AI, against a scripted chat model and a deterministic embedding model instead of a provider.

        The test application context holds a chatModel, an embeddingModel, a prototype chatClientBuilder over the scripted model and, when Spring AI's vector store module is on the classpath, an in-memory vectorStore; a service under test gets them by injection as it would get the real ones. Script the answers with respondWith(String...) and assert on getPrompts(). The script, the prompts and the vector store are cleared before every feature method.

        The stubs are registered before the specification's setupSpec, after the beans of its doWithSpring() and beanRegistrar() have been created, and each only when the context holds no bean of its type: a chat model, embedding model, chat client builder or vector store the specification defines is used instead. The chat model then has to be a ScriptedChatModel for getChatModel() and respondWith(String...) to find it. A bean defined in doWithSpring() that needs the builder at creation should take it from the context lazily, or be defined in setupSpec with defineBeans.

         class AnswerServiceSpec extends Specification implements ServiceUnitTest<AnswerService>, AiUnitTest {

     void 'answers with the model'() {
         given:
         respondWith('42')

         expect:
         service.answer('What is six times seven?') == '42'
         prompts.last().userMessage.text == 'What is six times seven?'
     }
 }
