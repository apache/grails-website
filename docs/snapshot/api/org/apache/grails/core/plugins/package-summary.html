Package org.apache.grails.core.plugins

  • Interface Summary 
    Interface Description
    PluginDiscovery Defines a strategy for discovering the Grails plugins that should participate in application bootstrap.
  • Class Summary 
    Class Description
    ClasspathPluginFinder Discovers Grails plugins from META-INF/grails-plugin.xml descriptors available on the classpath.
    DefaultPluginDiscovery Default PluginDiscovery implementation used during Grails bootstrap.
    PluginDescriptor Represents a parsed Grails plugin descriptor discovered on the classpath.
    PluginInfo Represents a discovered Grails plugin together with the metadata and resources needed during bootstrap.
    PluginMetadata Immutable metadata extracted from a Grails plugin class during discovery.
    PluginUtils Static utility methods supporting Grails plugin discovery, metadata extraction, configuration lookup, and compatibility checks.
