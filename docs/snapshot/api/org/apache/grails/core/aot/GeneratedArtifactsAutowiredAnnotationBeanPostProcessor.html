[Java] Class GeneratedArtifactsAutowiredAnnotationBeanPostProcessor

      • org.apache.grails.core.aot.GeneratedArtifactsAutowiredAnnotationBeanPostProcessor 
      • public class GeneratedArtifactsAutowiredAnnotationBeanPostProcessor
extends AutowiredAnnotationBeanPostProcessor

        Injects through @Autowired, @Value and @Inject what the code generated ahead of time did not: an instance that code created only through the members its class adds to the type the definition names, and every other bean in full.

        Another instance of a generated bean is injected in full as Spring injects any bean: the common processor comes first, and a member it injects, one annotated with @Resource as well, is left to it.
