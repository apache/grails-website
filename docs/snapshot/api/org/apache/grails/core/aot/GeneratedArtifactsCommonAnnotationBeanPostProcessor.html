Package: org.apache.grails.core.aot

[Java] Class GeneratedArtifactsCommonAnnotationBeanPostProcessor

        • org.apache.grails.core.aot.GeneratedArtifactsCommonAnnotationBeanPostProcessor 
        • public class GeneratedArtifactsCommonAnnotationBeanPostProcessor
extends CommonAnnotationBeanPostProcessor

          Injects through @Resource what the code generated ahead of time did not: an instance that code created only through the members its class adds to the type the definition names, and every other bean in full.

          It calls @PostConstruct and @PreDestroy methods as Spring's own does, for every instance. The names the generated code recorded for them are taken off its definitions when this is registered, see GeneratedBeanDefinitions.leaveAnnotatedLifecycleMethodsToProcessor.

          Since:
          8.0.1
