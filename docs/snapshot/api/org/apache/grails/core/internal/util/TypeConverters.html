Package: org.apache.grails.core.internal.util

[Java] Class TypeConverters

    • org.apache.grails.core.internal.util.TypeConverters 
    • public final class TypeConverters
extends java.lang.Object

      Internal helpers that convert a raw Object value to a target type without allocating an intermediate map. These power the type conversion methods on TypeConvertingMap and the servlet attribute extensions, keeping the conversion logic in a single place.

      This is an internal class and is not part of the public Grails API.

      Since:
      8.0
