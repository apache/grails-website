Package: org.apache.grails.data.simple.querytail

[Groovy] Class SimpleMapStatements

    • org.apache.grails.data.simple.querytail.SimpleMapStatements 
    • @CompileStatic
final class SimpleMapStatements
extends java.lang.Object

      Builds the statements the simple datastore records for query-tail, in the shape of SQL, from a query and the mapping rather than from text, so no value ever reaches one: every value is QueryTailRedactor.PLACEHOLDER, and so is every name the mapping does not know, such as a property name a query took from a request, and every segment of a path past one. A query is recorded as select * from Book where title = ? order by title asc limit ?, with its projections in place of *, the criteria of an association as paths through it and a subquery in parentheses. An entry read by its key is select * from Book where id = ?, entries read by their keys together are select * from Book where id in (?), and the writes are insert into Book, update Book where id = ? and delete from Book where id = ?. The name after from is the family the entity's entries are kept in: its class name, unless its mapping names another.
