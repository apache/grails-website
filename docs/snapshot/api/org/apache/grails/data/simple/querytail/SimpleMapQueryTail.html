Package: org.apache.grails.data.simple.querytail

[Groovy] Class SimpleMapQueryTail

    • org.apache.grails.data.simple.querytail.SimpleMapQueryTail
    • All Implemented Interfaces and Traits:
      java.io.Closeable
      @CompileStatic
class SimpleMapQueryTail
extends java.lang.Object
implements java.io.Closeable

      The query-tail capture of a connection source of the simple datastore, which GORM creates when capture is enabled. The simple datastore keeps its entries in memory and runs no statements, so it records what GORM asks of it as statements, which SimpleMapStatements builds from the query and the mapping without a value in them: a query, an entry read by its key, entries read by their keys together, and each insert, update and delete.

      A read is recorded once, however much it reads: the entries a query reads to find, sort and load its rows, the associations an entry loads as it is read, and the entries a write reads, are part of that read or that write, and are not recorded on their own. An association loaded later, as a proxy or a lazy collection is when it is first used, is a read of its own. What a read is part of is tracked per thread, as the reads of a session run on the thread that uses it.

      The capture opens when the datastore is built and closes with it. Nothing of this is created unless QueryTailSettings.SETTING_ENABLED is set, so a datastore that does not capture pays nothing per operation.
