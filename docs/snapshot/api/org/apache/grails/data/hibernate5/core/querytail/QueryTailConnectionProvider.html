final class QueryTailConnectionProvider<S extends Service>
extends java.lang.Object
implements org.hibernate.service.spi.SessionFactoryServiceInitiator<S>

      Decorates the connection provider of a session factory: the one its service registry takes from the registry the session factory is built with, whatever put it there, Hibernate's own initiator, or an initiator or a service a configuration class added. The sessions of the session factory take their connections from it, so the statements they run are recorded, while the schema work Hibernate does through the registry the session factory is built with is not. Connections are captured at execution and returned to their provider as the original instances. The provider stays the service of the registry it came from, which configures, starts and stops it, so the decoration takes no part in its lifecycle.
