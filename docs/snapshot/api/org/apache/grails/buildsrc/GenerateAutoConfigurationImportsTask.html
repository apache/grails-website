Package: org.apache.grails.buildsrc

[Groovy] Class GenerateAutoConfigurationImportsTask

      • org.apache.grails.buildsrc.GenerateAutoConfigurationImportsTask 
      • abstract class GenerateAutoConfigurationImportsTask
extends DefaultTask

        Scans this project's own compiled main classes for @AutoConfiguration and writes META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports, so the file never needs to be hand-maintained. Mirrors how META-INF/grails-plugin.xml is already generated from scanned *GrailsPlugin classes elsewhere in this build.

        Class files are read directly with ASM rather than loaded. Loading required every supertype and annotation of every candidate to be resolvable, and a candidate that failed to load could only be warned about and skipped - so a genuine @AutoConfiguration could drop out of the generated file while the build stayed green, which is the outcome this task exists to prevent. Reading the annotation table needs nothing beyond the class file itself, so that failure mode is gone and there is no scan classpath to get wrong.
