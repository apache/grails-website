Package: org.apache.grails.startup

[Java] Class StartupProgressProperties

    • org.apache.grails.startup.StartupProgressProperties 
    • @ConfigurationProperties(prefix = "grails.startup.progress")
public class StartupProgressProperties
extends java.lang.Object

      Settings for the page Grails serves on the application's port while the application starts, bound from grails.startup.progress.*.

      Both settings default to on in development mode, that is when the environment is development and the application runs from its project directory, as it does under bootRun, and to off otherwise.

      Since:
      8.1
