Package: org.apache.grails.datamapping.core.querytail

[Groovy] Class QueryTailRecord

    • org.apache.grails.datamapping.core.querytail.QueryTailRecord 
    • @CompileStatic
@EqualsAndHashCode
@ToString(includeNames=true)
class QueryTailRecord
extends java.lang.Object

      One captured statement, SQL, Cypher, a MongoDB command or an operation of the simple datastore: when it ran, which data source ran it, the web request it belongs to and the page (controller and action) that request was serving. A record is one line of the capture file, tab separated, which is what the query-tail command reads back. The first line of the file is not a record but its header, which names the run that wrote it.

      The whitespace of a statement is collapsed to single spaces in its line, but for that inside its quoted names and literals, which is kept as written: two names that differ only in their spaces are two names. A tab or a line break kept that way is written as \t, \n or \r, and a backslash anywhere in the statement as two, so that the line format holds and the statement reads back as it was written. A document statement, one recorded without its values already, as a MongoDB command, whose names are quoted as JSON quotes them rather than as SQL does, and an operation of the simple datastore are, is written as it was recorded, with only those characters escaped, and its line says so, so that it is never read as SQL.
