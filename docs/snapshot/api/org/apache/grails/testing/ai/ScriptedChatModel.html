Package: org.apache.grails.testing.ai

[Groovy] Class ScriptedChatModel

    • org.apache.grails.testing.ai.ScriptedChatModel
    • All Implemented Interfaces and Traits:
      ChatModel
      @CompileStatic
class ScriptedChatModel
extends java.lang.Object
implements ChatModel

      A chat model that answers with scripted responses instead of calling a provider, and records every prompt it receives, so a test can drive the code that uses a ChatClient and assert on what it asked.

      Responses are consumed in the order they were scripted; a response may be fixed text or a function of the prompt. When none is left, the model echoes the text of the last user message, so a test that does not care about the answer still gets one; a strict model fails instead, for a test that must not run out of script unnoticed. A streamed call answers in chunks of one word each, so code that assembles a stream is exercised as it would be against a real model. The answer of a streamed call is taken when the Flux is subscribed, not when it is created, so a stream that is never subscribed consumes nothing and a retried one answers afresh.
