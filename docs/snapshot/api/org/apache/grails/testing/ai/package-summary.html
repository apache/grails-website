Package org.apache.grails.testing.ai

  • Class Summary 
    Class Description
    AiStubEnvironmentPostProcessor Turns the provider auto-configurations off while the stubs are enabled, so a test environment needs neither credentials nor a database: every spring.ai.model.* selection property, the chat, embedding, image, audio and moderation models', and spring.ai.vectorstore.type default to none.
    AiStubProperties Settings of the stubs that stand in for the configured Spring AI provider while this module is on the classpath, under grails.ai.stub.
    AiTestBeans The beans a unit test gets from AiUnitTest: the scripted chat model, the stub embedding model, a ChatClient.Builder over the chat model, and an in-memory vector store when Spring AI's vector store module is on the classpath.
    AiTestingAutoConfiguration Registers a ScriptedChatModel and a StubEmbeddingModel in place of the provider's models while grails.ai.stub.enabled is true, which it is by default when this module is on the classpath.
    AiTestingVectorStoreAutoConfiguration Registers an in-memory vector store over the stub embedding model when Spring AI's vector store module is on the classpath, no vector store is selected and the application defines none, so code that stores and searches documents can be tested without a database.
    ResettableSimpleVectorStore The in-memory vector store a unit test gets: a SimpleVectorStore that can be emptied, so every feature method starts without the documents the previous one added.
    ScriptedChatModel A chat model that answers with scripted responses instead of calling a provider, and records every prompt it receives, so a test can drive the code that uses a ChatClient and assert on what it asked.
    SimpleVectorStoreBeans Registers and resets the in-memory vector store a unit test gets.
    StubEmbeddingModel An embedding model that computes a vector from the words of the text instead of calling a provider.
