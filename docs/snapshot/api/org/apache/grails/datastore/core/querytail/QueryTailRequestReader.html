Package: org.apache.grails.datastore.core.querytail

[Java] Interface QueryTailRequestReader

  • public interface QueryTailRequestReader

    Reads what the web framework that routed a request resolved it to, for the query-tail capture: the page the statements of the request are counted under, and how the path of the request reads with the values in it replaced. The capture finds the readers on its class path with java.util.ServiceLoader, so that it reads the requests of a framework without depending on it, and asks each in turn until one has resolved the request; Grails URL mapping provides one. A request no reader resolves has no page, and its path is recorded as the pattern a Spring MVC handler mapping matched, or by its shape alone.

    A reader is asked for every statement a request runs, which may be hundreds, so one that has work to do keeps what it found in an attribute of the request, and finds it there again until what it found it from changes. The capture reads the path of a request again only when the request moves on, or when the target it is given is another one, so a reader returns the same target for as long as the request is resolved to the same thing.

    Recording never fails the statement it records: a reader that throws is passed over, and the request is recorded as if it had resolved nothing.
