[Groovy] Class ComponentSchemas

    • org.grails.openapi.ComponentSchemas 
    • @CompileStatic
class ComponentSchemas
extends java.lang.Object

      The schemas a document holds in its components: resolved from classes through swagger-core, derived from them, such as a patch, and named so that no two share a name.
