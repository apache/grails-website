Package: org.grails.async.factory.groovy

[Groovy] Class AwaitablePromiseFactory

      • org.grails.async.factory.groovy.AwaitablePromiseFactory 
      • @AutoFinal
@CompileStatic
class AwaitablePromiseFactory
extends AbstractPromiseFactory

        A PromiseFactory built on Groovy's groovy.concurrent API.

        Tasks run through Awaitable, unfulfilled promises are DataflowVariable instances, and lists of promises are combined with Awaitable.all. Without an explicit executor, tasks are submitted to the executor Groovy uses for async blocks, Awaitable.getExecutor, which is a virtual-thread executor on Java 21 and later.

        Both direct and chained get() calls report failures as java.util.concurrent.ExecutionException with the original failure as the cause. Error callbacks receive the original failure. A single-promise onError recovers with its callback result; the aggregate onError observes the failure and leaves the returned promise failed.

          • <T> protected Awaitable<java.util.List<java.lang.Object>> all(java.util.List<Promise<T>> promises)

            Combines the promises with Awaitable.all. Promises created by this factory, and any other Awaitable or java.util.concurrent.CompletionStage, are combined directly. Any other promise that is already done is read inline; a pending one is awaited on this factory's executor so that bridging work never lands on a pool the factory does not own.
