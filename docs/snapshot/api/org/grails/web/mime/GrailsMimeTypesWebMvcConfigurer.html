[Groovy] Class GrailsMimeTypesWebMvcConfigurer

    • org.grails.web.mime.GrailsMimeTypesWebMvcConfigurer
    • All Implemented Interfaces and Traits:
      WebMvcConfigurer
      @CompileStatic
@Order(value=Ordered.HIGHEST_PRECEDENCE)
class GrailsMimeTypesWebMvcConfigurer
extends java.lang.Object
implements WebMvcConfigurer

      Registers the configured Grails data formats with Spring MVC as format aliases, which Spring negotiates with only when parameter negotiation is enabled, and which count among the safe extensions of its reflected-file-download check, and holds the strategy Grails' own format resolution uses.

          Parameters:
          strategySupplier - builds the strategy on first use. Spring MVC collects its configurers while its own infrastructure beans are created, so a configurer that needed the MIME types when it was created would pull in every bean that supplies them, and fail on a cycle.
          dataFormatMimeTypes - the MIME types whose data formats are registered with Spring MVC, which it asks for while its content negotiation manager is created, so that they are not those of the strategy, whose MIME types can come from beans that need that manager
