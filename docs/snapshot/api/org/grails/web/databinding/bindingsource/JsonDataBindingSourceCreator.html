            • protected tools.jackson.databind.ObjectReader untypedReader()

              Reads untyped JSON values. Decimals are read as BigDecimal so that binding a fractional value to a BigDecimal property keeps the digits the request sent; reading them as doubles first would round them before the binder ever saw them. A body is read as it is, without a root value, which the mapper would otherwise expect for Object where it unwraps root values, and its arrays as lists and its whole numbers as the smallest of Integer, Long and BigInteger that holds them, as the legacy parser reads them, whatever the mapper's features say, and without the type ids the mapper's default typing would have a body carry, so that a body binds without them and cannot name a class to create.

              Since:
              9.0
