Package: org.grails.web.databinding

[Java] Class BindingIncludeLists

    • org.grails.web.databinding.BindingIncludeLists 
    • @java.lang.SuppressWarnings({"rawtypes", "unchecked"})
public final class BindingIncludeLists
extends java.lang.Object

      The properties data binding binds on a type: the include list Grails generates for a domain class or a command object, and under grails.databinding.denyByDefault the properties constrained bindable: true. Everything it is read from belongs to the class, so it is read from the class, without an instance, and kept for each class.

      Internal to Grails: grails.web.databinding.DataBindingUtils binds with it, and other Grails modules read it through it.

      Since:
      8.0

        • public static boolean resolveDenyByDefault(java.lang.Object value)

          Resolves the configured value of grails.databinding.denyByDefault against the permissive default.

          The raw value must be resolved here rather than through a typed Boolean config lookup: a config value that converts to Boolean.FALSE is discarded in favour of the supplied default, which would silently ignore an explicit value from any string-valued source such as a properties file, a system property or an environment variable.

          A navigable config answers an absent key with a placeholder object rather than null, so only a genuinely absent key may fall back to the permissive default. Any other unrecognised value fails closed, because this switch governs mass-assignment protection.

          Parameters:
          value - the raw configured value, which may be null or an absent-key placeholder
          Returns:
          true when secure deny-by-default binding applies
