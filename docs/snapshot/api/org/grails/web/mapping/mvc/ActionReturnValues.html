Package: org.grails.web.mapping.mvc

[Groovy] Class ActionReturnValues

    • org.grails.web.mapping.mvc.ActionReturnValues 
    • @CompileStatic
class ActionReturnValues
extends java.lang.Object

      Writes the value a controller action returns as Spring MVC writes the value a handler method returns, where Spring MVC writes it as the response: an HttpEntity, such as a ResponseEntity, HttpHeaders, a ProblemDetail, an ErrorResponse, a StreamingResponseBody or a ResponseBodyEmitter, and, with grails.controllers.responseBody, any value of an action annotated @ResponseBody, or of an action of a controller annotated so. The action is the handler method, typed by the value it returns, as Spring MVC types the value of a handler method declared to return Object, and the value is handed to the return value handlers of Spring MVC's handler adapter, with the status of the action's @ResponseStatus, so that the advice for the controller and the annotations of the action, such as @JsonView, apply as they do to a Spring MVC controller. An asynchronous value, such as a CompletableFuture or a DeferredResult, is processed as Spring MVC processes one, with the executor, timeout and interceptors of the handler adapter, and the value it completes with is written as the action's.
