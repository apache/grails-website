Package: org.grails.web.json

[Java] Class JsonMapperSupport

    • org.grails.web.json.JsonMapperSupport 
    • public final class JsonMapperSupport
extends java.lang.Object

      The Jackson tools.jackson.databind.json.JsonMapper that grails.converters.JSON writes through: Spring Boot's auto-configured mapper in an application, so that spring.jackson.* settings apply, or a default mapper otherwise.

      The mapper writes the JSON token stream, and writes every value that it has a dedicated serializer for, such as dates and times, Month, UUID, Locale, byte[], types with a @JsonValue and the types that Jackson modules registered with the application serialize. Grails marshallers still render domain classes, beans, records, enums, collections, maps, arrays and Optional, so the values they contain are rendered as any other value is. The JSON text is written through HtmlSafeJsonWriter.

      JSON is written with a copy of the mapper whose serializers offer the values nested in a value they write, such as a property that a module's serializer writes, to the nested value writer the value is written with (writeValue(JsonGenerator, Object, Predicate)), so that Grails marshallers render those values as well.

Beans, records, enums other than those with their own serializer (such as Month), including an enum with a @JsonValue, Optional and other reference types, collections, maps, iterables, streams and object arrays are left to Grails marshallers, so that the values they contain are rendered as any other value is.

        • public void writeValue(tools.jackson.core.JsonGenerator generator, java.lang.Object value)

          Writes a value with the mapper, as a value inside the JSON document the generator is writing. Inside a value written with writeValue(JsonGenerator, Object, Predicate), the value takes part in that nested write: it is offered to the nested value writer first, as any value nested in that value is.

          Parameters:

        • public void writeValue(tools.jackson.core.JsonGenerator generator, java.lang.Object value, java.util.function.Predicate<java.lang.Object> nestedValueWriter)

          Writes a value with the mapper, as a value inside the JSON document the generator is writing, and offers each value nested in it, such as a property that a module's serializer writes with tools.jackson.core.JsonGenerator#writePOJO(java.lang.Object), to a nested value writer first. The writer either writes the nested value to the generator, as one complete JSON value, and returns true, or returns false for the mapper to write it.
