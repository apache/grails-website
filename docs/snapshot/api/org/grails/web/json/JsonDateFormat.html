Package: org.grails.web.json

[Java] Class JsonDateFormat

    • org.grails.web.json.JsonDateFormat 
    • public final class JsonDateFormat
extends java.lang.Object

      Formats java.util.Date and java.util.Calendar values for JSON the way Jackson's default StdDateFormat does, which is how Spring Boot renders them: a UTC instant that always has millisecond precision and a Z suffix, e.g. 2024-06-15T14:30:45.000Z.

      Works from epoch milliseconds, so java.sql.Date, java.sql.Time and java.sql.Timestamp (whose sub-millisecond nanos are dropped) format the same way as a plain Date; java.sql.Date#toInstant() and java.sql.Time#toInstant() would throw. Fields are read from a java.util.GregorianCalendar, the calendar system of java.util.Date, so dates before the 1582 Gregorian cutover use the Julian calendar. Years after 9999 get a + sign and years before 1 AD use ISO 8601 numbering (1 BC is +0000, 2 BC is -0001).
