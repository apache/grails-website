          • public static final java.lang.String SETTING_CONVERTERS_JSON_DOMAIN_JACKSON_ENABLED

            Whether domain classes are registered with the application's JsonMapper, so that it renders them with the serializer the JSON converter renders them with when SETTING_CONVERTERS_JSON_LEGACY is false, including when a Spring MVC controller returns one; the marshallers and the rule for enums the converter applies on top do not apply there. Defaults to false, so that the application's JsonMapper renders domain classes as Jackson beans, as it did in Grails 8. The JSON converter's rendering does not depend on it.

            Since:
            9.0

          • public static final java.lang.String SETTING_CONVERTERS_JSON_LEGACY

            Whether the JSON converter renders values as Grails 8 did, with the marshallers of Grails 8 rather than the application's JsonMapper. Defaults to true in Grails 9: set it to false to render JSON through the application's JsonMapper, which Grails 10 makes the default, together with grails.web.rendering.json.spring and grails.databinding.json.jackson.

            Since:
            9.0
