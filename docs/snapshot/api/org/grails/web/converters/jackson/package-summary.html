Package org.grails.web.converters.jackson

  • Interface Summary 
    Interface Description
    DomainClassRenderer An object marshaller that renders domain class instances, and says how: with which DomainClassRendering the JSON converter writes an instance of a domain class through a mapper that has a DomainClassJacksonModule.
  • Class Summary 
    Class Description
    ConverterJsonModule The rules grails.converters.JSON adds to the mapper it writes with: an enum is written by its name, so that it binds back, validation errors are written without the values that were rejected, a bean leaves out the properties of the methods annotated @PersistenceMethod and @ControllerMethod, and the converter's includes and excludes for the class of a bean decide which of its properties are written, naming each by the name the class gives it or by the name it is written with.
    DomainClassJacksonModule A Jackson module that serializes domain class instances, and proxies of them, as grails.converters.JSON renders them when grails.converters.json.legacy is false, which writes them with this module, and applies the marshallers registered with it and its own rule for enums on top.
    DomainClassRendering How a DomainClassJacksonModule renders domain class instances: whether it writes the version and the class name, whether it renders associated domain class instances in full (deep) or as references of their id, and which properties it writes.
    GrailsJsonMapperCustomizer Adds Grails-specific serializers to Spring Boot's configured JSON mapper.
    JacksonNamedJsonRenderer Jackson implementation shared by render and respond.
    JsonProjection A per-write includes/excludes projection, as the render and respond arguments request it.
