Package: org.grails.web.converters.jackson

[Java] Class DomainClassRendering

    • org.grails.web.converters.jackson.DomainClassRendering 
    • public class DomainClassRendering
extends java.lang.Object

      How a DomainClassJacksonModule renders domain class instances: whether it writes the version and the class name, whether it renders associated domain class instances in full (deep) or as references of their id, and which properties it writes.

      The defaults are the converter's JSON defaults (grails.converters.json.domain.include.version, grails.converters.json.domain.include.class and grails.converters.json.default.deep), and every persistent property is written except those Jackson leaves out, such as a property annotated @JsonIgnore or named by @JsonIgnoreProperties. GORM adds that annotation to every domain class, naming properties such as errors and tenantId; the version is written when it is included regardless. Subclasses override the methods to render differently. Whether a domain class can have the class name and the version written ahead of its properties is decided once, when a module builds the class's serializer, from isIncludeClass() and isIncludeVersion() of the module's own rendering, unless the module is created to take the rendering of each instance from the writes, with DomainClassJacksonModule.RENDERINGS. Each write then reads them again, so a rendering can leave them out for a write, but not write one its class was built without.
