Package: org.grails.web.converters.jackson

[Java] Class DomainClassJacksonModule

      • org.grails.web.converters.jackson.DomainClassJacksonModule 
      • public class DomainClassJacksonModule
extends tools.jackson.databind.JacksonModule

        A Jackson module that serializes domain class instances, and proxies of them, as grails.converters.JSON renders them when grails.converters.json.legacy is false, which writes them with this module, and applies the marshallers registered with it and its own rule for enums on top. Grails responses write with it, and a Grails application registers it with the application's JsonMapper when grails.converters.json.domain.jackson.enabled is set, so that returning a domain class instance from a Spring MVC controller writes it with the same serializer.

        An instance is written by Jackson's bean serializer, which is shaped to the domain class: the class name, the id and the version where they apply, then the persistent properties in the order the domain class declares them, with an associated instance as a reference of its id, or in full when rendering deep. What Jackson applies to a bean therefore applies to an instance: the mapper's naming strategy and inclusion, @JsonIgnore, @JsonInclude, @JsonView, @JsonFormat, @JsonProperty, @JsonNaming, @JsonTypeInfo, @JsonUnwrapped, @JsonAnyGetter on a persistent property, mixins and filters. A domain class with its own @JsonSerialize serializer keeps it, and so does one with a @JsonValue, that implements JacksonSerializable, or that a module has a serializer for, which Jackson writes as it writes any class; an associated instance of such a class is written with that serializer too, unless the rendering writes the references itself, or Jackson cannot build the serializer, which a reference does not need. Whether a proxy is written with such a serializer is decided by the domain class the association declares, since the class of the instance it stands for is known only once it is loaded. A subclass of a domain class that is neither a domain class nor a proxy class of one is written as a Jackson bean.

          • public static final java.lang.String DEEP

            A writer attribute for a writer that writes the associated instances of the domain class instances it writes in full, rather than as references of their ids, as grails.converters.json.default.deep does for every write. Its value is java.lang.Boolean#TRUE.

          • public static final java.lang.String RENDERINGS

            A writer attribute for a writer that renders the domain class instances it writes in its own ways. Its value is a Function<Object, DomainClassRendering> that gives the rendering of an instance, or null for the module's. The JSON converter renders each instance with its own includes and excludes this way. A module whose writes do this is created with renderingsPerWrite.

          • public static final java.lang.String STAND_INS

            A writer attribute for a writer that is told of each proxy the module writes as the instance it proxies, before it writes the instance. Its value is a BiConsumer<Object, Object> that is given the proxy and the instance. The JSON converter applies the includes and excludes it has for the class of the proxy to the instance this way.
