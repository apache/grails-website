          Prepares a writer of the Grails mapper for one write through a generator it did not create in that write, as Spring's Jackson converter creates its generator before it writes: the objects being written are kept for the whole write, so that a value a serializer writes with writePOJO, which the generator writes, is found where it repeats one being written, as in one write of the mapper.

          Parameters:

        • public static tools.jackson.databind.json.JsonMapper.Builder withGrailsModules(tools.jackson.databind.json.JsonMapper mapper, tools.jackson.databind.JacksonModule grailsModules)

          A copy of an application's mapper with Grails modules, which the JSON converter and Grails responses derive their mappers with. The Grails modules are installed ahead of the application's, so that the application's serializers keep their precedence over them, and a DomainClassJacksonModule of the application's mapper is replaced by the one given.

          Parameters:
          mapper - the application's mapper
          grailsModules - the Grails modules
          Returns:
          a builder of the copy
