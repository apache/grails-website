Package: org.grails.web.converters.jackson

[Java] Class ConverterJsonModule

      • org.grails.web.converters.jackson.ConverterJsonModule 
      • public final class ConverterJsonModule
extends tools.jackson.databind.JacksonModule

        The rules grails.converters.JSON adds to the mapper it writes with: an enum is written by its name, so that it binds back, validation errors are written without the values that were rejected, a bean leaves out the properties of the methods annotated @PersistenceMethod and @ControllerMethod, and the converter's includes and excludes for the class of a bean decide which of its properties are written, naming each by the name the class gives it or by the name it is written with.

          • public static final java.lang.String PROPERTY_FILTERS

            A writer attribute for a writer that includes only some of the properties of the beans it writes. Its value is a Function<Object, BiPredicate<String, String>> that gives, for a bean, whether a property is written by the name the class gives it and the name it is written with, or null for all of them.
