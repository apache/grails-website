Package: org.grails.plugins.i18n

[Java] Record I18nDescriptor

      • org.grails.plugins.i18n.I18nDescriptor 
      • public record I18nDescriptor
extends java.lang.Record

        The message bundles one application or plugin contributes, as recorded in its META-INF/grails/i18n.properties at build time.

        Base names and locales are already normalised by the Grails Gradle plugin, so nothing here re-parses file names. That is deliberate: the base-name list handed to Spring Boot, the locale list offered by AvailableLocaleResolver, and the native-image resource hints all read the same pre-computed values and therefore cannot disagree about what a file name means.

        Parameters:
        type - either TYPE_APPLICATION or TYPE_PLUGIN
        name - the application name, or the Grails plugin name (e.g. spring-security-core)
        version - the artifact version; recorded for diagnostics only, never for ordering
        basenames - base names for spring.messages.basename
        locales - locale identifiers (de, pt_BR) the bundles are translated into
        Since:
        8.0
