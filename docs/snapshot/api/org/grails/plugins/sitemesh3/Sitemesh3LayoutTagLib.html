Package: org.grails.plugins.sitemesh3

[Groovy] Class Sitemesh3LayoutTagLib

    • org.grails.plugins.sitemesh3.Sitemesh3LayoutTagLib
    • All Implemented Interfaces and Traits:
      TagLibrary
      @groovy.transform.CompileStatic
@TagLib
class Sitemesh3LayoutTagLib
extends java.lang.Object
implements TagLibrary

      SiteMesh 3 counterpart of GrailsLayoutTagLib: populates a Sitemesh3CapturedPage at GSP render time so that SiteMesh 3 can decorate without parsing the HTML.

      Registered under the grailsLayout namespace because the GSP compile-time preprocessor (GrailsLayoutPreprocessor) rewrites <head>, <body>, etc. to <grailsLayout:capture*> tags.

        • java.lang.Object captureBody(java.util.Map attrs, groovy.lang.Closure body)

          Captures the <body> section of a GSP page, including any body attributes (e.g. onload), into the Sitemesh3CapturedPage. Invoked automatically by the GSP compile-time preprocessor; not intended for direct use in templates.

          attr:
          onload optional — body onload handler, stored as body.onload
          attr:
          class optional — body CSS class, stored as body.class

        • java.lang.Object captureContent(java.util.Map attrs, groovy.lang.Closure body)

          Captures a named content block from a GSP page into the Sitemesh3CapturedPage so it can be retrieved in the layout via <g:pageProperty name="page.<tag>">. Equivalent to SiteMesh 2's <content tag="..."> but populated at GSP render time rather than via HTML parsing.

          attr:
          tag REQUIRED the name of the content block (e.g. navbar)

        • java.lang.Object captureHead(java.util.Map attrs, groovy.lang.Closure body)

          Captures the <head> section of a GSP page into the Sitemesh3CapturedPage so the layout can inline it without re-parsing HTML. Invoked automatically by the GSP compile-time preprocessor; not intended for direct use in templates.

        • java.lang.Object captureMeta(java.util.Map attrs, groovy.lang.Closure body)

          Captures <meta> tag attributes and registers them as page properties (e.g. meta.layout, meta.author) on the Sitemesh3CapturedPage. Invoked automatically by the GSP compile-time preprocessor; not intended for direct use in templates.

          attr:
          content optional — the content attribute value to store
          attr:
          http-equiv optional — the http-equiv attribute of the meta tag
