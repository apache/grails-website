        • final java.lang.Class<T> targetType

        • java.lang.Boolean useSpringJson

          Whether responses are written by Spring's message converters rather than the legacy JSON converter. Left unset, the renderer registry applies grails.web.rendering.json.spring; unset outside a registry means the legacy path. Grails 9 defaults to the legacy path; Grails 10 opts into Spring by default and Grails 11 removes the legacy response path.

        • ValidationProblemDetailFactory validationProblemDetailFactory

          Left unset, the registry's factory is used, or a default one outside a registry.
