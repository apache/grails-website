Package: org.grails.plugins.web.rest.render.json

[Groovy] Class GrailsMapperJsonConverter

            • org.grails.plugins.web.rest.render.json.GrailsMapperJsonConverter 
            • @CompileStatic
class GrailsMapperJsonConverter
extends JacksonJsonHttpMessageConverter

              Spring's Jackson JSON converter with the Grails mapper, which writes a response as the application's converter writes it, with the types it writes and its prefix, and with the projection of the response, and in text/json too, which the Grails json format has.

              Since:
              9.0
