class PublisherActionResultTransformer
extends java.lang.Object
implements ActionResultTransformer

      Streams a org.reactivestreams.Publisher returned from a controller action to the client as server-sent events.

      The request is handled asynchronously through Spring MVC, as a returned Promise is, so the container thread is released while the stream produces. The response is committed as text/event-stream before the first item, and each item is written as soon as it is emitted, formatted by a ServerSentEventFormatter. A publisher that emits at most one item, such as a Reactor Mono, is not streamed: as Spring MVC does, Grails resolves it and treats its value as the action's result, the way a returned Promise's value is; which publishers are single-valued is what Spring's ReactiveAdapterRegistry says. A stream has no timeout, as Spring MVC's server-sent event streams have none, unless grails.async.streaming.timeout sets one; a timeout ends the stream with a complete event, since the response is already committed.
