      org.reactivestreams.Subscriber<java.lang.Object>
      @CompileStatic
@Slf4j
class ServerSentEventSubscriber
extends java.lang.Object
implements org.reactivestreams.Subscriber<java.lang.Object>

      Writes the items of a stream to the response as server-sent events, one at a time, and completes the deferred result that holds the request open when the stream ends.

      Items are requested one by one, so a publisher that honours back-pressure produces no faster than the response is written. Every stream ends with a complete event, so an EventSource can close instead of reconnecting: its data is empty when the publisher completed, timeout when the container timed the request out and error when the publisher failed or an item could not be rendered, since the response was committed when streaming began and cannot carry an error status any more. The failure itself is logged on the server and nothing of it reaches the client. A client that disconnects is detected by the failed write and the stream is cancelled.

      The publisher emits on its own thread while the container reports a timeout on another, so every write to the response, and the check that the stream is still open before it, happens under one lock; two events can never interleave on the wire.
