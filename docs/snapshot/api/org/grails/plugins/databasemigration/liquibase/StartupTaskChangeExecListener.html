[Groovy] Class StartupTaskChangeExecListener

      • org.grails.plugins.databasemigration.liquibase.StartupTaskChangeExecListener 
      • @CompileStatic
class StartupTaskChangeExecListener
extends liquibase.changelog.visitor.AbstractChangeExecListener

        Reports each change set of a database update as an item of a StartupTask, so a start that migrates the database shows which change set it is on and how many it has run.
