Package org.grails.taglib.discovery

  • Interface Summary 
    Interface Description
    TagLibraryView A tag library as the rules need to read it, whether from a syntax tree or from a compiled class.
    TagMethodView The properties of a method that decide whether it is a tag.
  • Class Summary 
    Class Description
    AstTagLibraryView A tag library read from its syntax tree, as a build reads one while compiling it.
    AstTagMethodView A method being compiled, seen through TagMethodView so that TagDiscoveryRules can classify it before the class exists.
    ReflectedTagLibraryView A tag library read from its compiled class, as an application reads one when it registers it.
    ReflectedTagMethodView A compiled method, seen through TagMethodView so that TagDiscoveryRules can classify it at runtime.
    TagDiscoveryRules Decides whether a method is a tag.
    TagLibraryAstDiscovery Reads a tag library's namespace and tag names from its syntax tree.
