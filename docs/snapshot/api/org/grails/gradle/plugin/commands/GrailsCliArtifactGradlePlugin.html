Package: org.grails.gradle.plugin.commands

[Groovy] Class GrailsCliArtifactGradlePlugin

    • org.grails.gradle.plugin.commands.GrailsCliArtifactGradlePlugin
    • All Implemented Interfaces and Traits:
      Plugin<Project>
      @groovy.transform.CompileStatic
abstract class GrailsCliArtifactGradlePlugin
extends java.lang.Object
implements Plugin<Project>

      Configures a Grails plugin project to ship its CLI commands as a companion artifact under its own Maven coordinate (<artifactId>-cli), keeping command code and CLI-only dependencies off the runtime classpath of consuming applications. Applying the plugin:

      • creates a cli source set (src/cli/groovy) exposed as a feature variant;
      • adds org.apache.grails:grails-core-cli (the command contract) and the plugin's own runtime classes to the cli compile classpath, so commands compile with no additional configuration and are registered automatically in META-INF/grails-cli.factories;
      • keeps the cli variants out of the plugin's default publication and exposes them through a dedicated cli software component;
      • stamps the runtime jar with the Grails-Cli-Artifact manifest attribute, so the Grails Gradle plugin adds the companion to a consuming application's grailsCli configuration automatically;
      • registers the companion publication with the Grails publish plugin (org.apache.grails.gradle.grails-publish) when it is applied.
      Configure through the cliArtifact extension: 
       cliArtifact {
     automaticModuleName = 'com.example.myplugin.cli'
 }
