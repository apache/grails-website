Package: org.grails.gradle.plugin.core

[Groovy] Class GrailsQueryTailRunProvider

    • org.grails.gradle.plugin.core.GrailsQueryTailRunProvider
    • All Implemented Interfaces and Traits:
      CommandLineArgumentProvider
      @CompileStatic
class GrailsQueryTailRunProvider
extends java.lang.Object
implements CommandLineArgumentProvider

      Hands a test JVM the name of the query-tail run of the build, -Dgrails.gorm.queryTail.run: a capture that finds its file headed by that run appends to it. Every test JVM is told, whether capture is enabled by a Gradle property or by the configuration of the application, and a JVM that does not capture ignores it; a run the build is given as a Gradle property itself is passed as it is instead. The name changes with every build, so it is neither an input of the task nor part of what the build cache keys its results by.
