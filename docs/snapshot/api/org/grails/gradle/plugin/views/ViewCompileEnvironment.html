Package: org.grails.gradle.plugin.views

[Groovy] Class ViewCompileEnvironment

    • org.grails.gradle.plugin.views.ViewCompileEnvironment 
    • @CompileStatic
final class ViewCompileEnvironment
extends java.lang.Object

      The Grails environment a build compiles its views for.

      Pages, JSON views and markup views are compiled ahead of time by a forked compiler that reads the application's configuration for the environment it runs in, so what a view compiles to - the codecs a page carries, for one - depends on that environment. The compile tasks state the environment as an input and hand it to the compiler, rather than leaving the compiler to whatever it inherits. This is where the input's default comes from, and how the input is read.
