Package: org.grails.datastore.gorm.transform

[Groovy] Class OrderedGormTransformation

      • org.grails.datastore.gorm.transform.OrderedGormTransformation
      • All Implemented Interfaces and Traits:
        CompilationUnitAware, TransformWithPriority
        @CompileStatic
@GroovyASTTransformation(phase: CompilePhase.CANONICALIZATION)
class OrderedGormTransformation
extends AbstractASTTransformation
implements CompilationUnitAware, TransformWithPriority

        Central AST transformation that ensures that GORM AST Transformations are executed in the correct order. Each GORM transform can implement the Ordered interface to achieve property placement. The transforms used by this cannot use TransformWithPriority because they iteratively get executed on each visited node, instead of executing only one transform across all nodes
