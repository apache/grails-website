[Java] Class ListResultFinder

    • org.grails.datastore.gorm.finders.ListResultFinder
    • All Implemented Interfaces and Traits:
      FinderMethod, QueryBuildingFinder
      public class ListResultFinder
extends java.lang.Object
implements FinderMethod, QueryBuildingFinder

      Implements every dynamic finder that returns a list of results: findAllBy* and the findAll<booleanProperty>By* boolean-clause form - configured via static factory methods rather than subclassed, composing a DynamicFinder grammar instead of extending it.
