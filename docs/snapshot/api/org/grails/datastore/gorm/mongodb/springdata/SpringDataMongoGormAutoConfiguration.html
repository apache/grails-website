@org.springframework.boot.autoconfigure.AutoConfigureAfter(name: org.grails.datastore.gorm.mongodb.boot.autoconfigure.MongoDbGormAutoConfiguration)
class SpringDataMongoGormAutoConfiguration
extends java.lang.Object

      Auto-configuration that wires Spring Data MongoDB on top of the same MongoDatastore (and therefore the same MongoClient, database and codecs) that GORM for MongoDB uses, and registers a primary transaction manager that lets GORM and Spring Data operations share a single MongoDB transaction.

      Activates only when Spring Data MongoDB is on the classpath and a GORM MongoDatastore bean is present. All beans are conditional on the application not already defining them, so an application that configures its own MongoTemplate, factory or transaction manager wins.
