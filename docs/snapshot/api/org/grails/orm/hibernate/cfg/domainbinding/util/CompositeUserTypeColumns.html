Package: org.grails.orm.hibernate.cfg.domainbinding.util

[Java] Class CompositeUserTypeColumns

    • org.grails.orm.hibernate.cfg.domainbinding.util.CompositeUserTypeColumns 
    • public class CompositeUserTypeColumns
extends java.lang.Object

      The columns of a property mapped with a Hibernate org.hibernate.usertype.CompositeUserType: one per persistent attribute of the org.hibernate.usertype.CompositeUserType#embeddable() of the user type, in the alphabetical order of the attribute names, which is the index that org.hibernate.usertype.CompositeUserType#getPropertyValue(java.lang.Object, int) and CompositeUserType#instantiate(org.hibernate.metamodel.spi.ValueAccess) use. The columns configured on the property are assigned to the attributes in that order, and an attribute without a configured column, or whose column has no name, is named after the property and the attribute. The binder of such a property binds these columns, and a uniqueness group that names the property spans all of them.

      The user type is instantiated here, for the binder of the property and for the uniqueness groups that name the property alike, the way Hibernate instantiates it when it resolves the type of a component: as a managed bean when the building options allow extensions in CDI, through its default constructor otherwise.

        • public static java.util.List<Attribute> attributesOf(java.lang.Class<?> embeddable)

          The persistent attributes of the embeddable class, in alphabetical order: the components of a record, or the fields and the readable bean properties of any other class, less the static, transient and synthetic ones, the ones every Groovy object has, the ones the class lists in transients and the ones backed by a transient field.
