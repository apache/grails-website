[Java] Class GrailsSqlRestrictionFunction

        • org.grails.orm.hibernate.query.GrailsSqlRestrictionFunction 
        • public class GrailsSqlRestrictionFunction
extends org.hibernate.query.sqm.function.AbstractSqmSelfRenderingFunctionDescriptor

          Renders a SqlRestriction as a predicate, in parentheses. The arguments are the SQL condition as a literal, a column of the queried entity whose table alias replaces {alias} if the SQL contains it, and the value of each ? placeholder.
