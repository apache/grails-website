Package: org.grails.orm.hibernate.query

[Java] Class SqlProjection

      • org.grails.orm.hibernate.query.SqlProjection 
      • public class SqlProjection
extends QueryProjection

        Projection that selects the value of a native SQL expression, created by sqlProjection or sqlGroupProjection in a criteria query. In the SQL, {alias} stands for the table alias of the queried entity.

        The SQL of a sqlProjection may select several columns, separated by commas, each one optionally followed by as and its column alias, as on Hibernate 5. It is split into one projection per column, so every column is a selection of its own.

        Since:
        8.0.1
