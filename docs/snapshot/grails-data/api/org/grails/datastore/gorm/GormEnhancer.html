        • protected void registerApiFactories()

          Registers the GormApiFactory implementations this enhancer's datastore needs, before any entity is registered. Adapters that build specialised API objects (for example Mongo's MongoStaticApi, which MongoEntity casts to) override this. It is deliberately separate from registerConstraints(Datastore): factory registration has nothing to do with constraints, and hanging it off the constraints hook would break the moment a subclass reordered or skipped that step.
