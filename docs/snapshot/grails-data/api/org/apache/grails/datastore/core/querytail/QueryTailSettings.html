Package: org.apache.grails.datastore.core.querytail

[Groovy] Class QueryTailSettings

    • org.apache.grails.datastore.core.querytail.QueryTailSettings 
    • @groovy.transform.builder.Builder(builderStrategy=SimpleStrategy, prefix="")
@groovy.transform.AutoClone
@groovy.transform.CompileStatic
class QueryTailSettings
extends java.lang.Object

      The settings of the query-tail capture: whether an application records the statements GORM runs, SQL through Hibernate, Cypher through Neo4j and commands through MongoDB, and where. Capture is off unless SETTING_ENABLED is set, so an application started without it carries nothing that records at all.
