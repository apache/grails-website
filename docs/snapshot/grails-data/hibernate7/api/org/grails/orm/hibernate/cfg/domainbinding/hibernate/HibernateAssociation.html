[Java] Interface HibernateAssociation

      • org.grails.datastore.mapping.model.PersistentProperty
      • All Superinterfaces:
        HibernatePersistentProperty, PersistentProperty
        public interface HibernateAssociation
extends HibernatePersistentProperty

        Common interface for all Hibernate association properties (both ToOne and ToMany). Extends HibernatePersistentProperty and declares the key Association methods directly so callers can use them without casting. Note: Association is an abstract class so cannot be listed as a super-interface; the implementing classes satisfy these contracts through their class hierarchy.
