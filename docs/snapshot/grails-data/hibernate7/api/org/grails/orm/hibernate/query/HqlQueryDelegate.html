Package: org.grails.orm.hibernate.query

[Java] Interface HqlQueryDelegate

  • public interface HqlQueryDelegate
extends java.io.Serializable

    Abstracts over Hibernate's org.hibernate.query.Query (SELECT) and org.hibernate.query.MutationQuery (UPDATE/DELETE). The two types are siblings under org.hibernate.query.CommonQueryContract and cannot be held in a single typed field, so HibernateHqlQueryCreator delegates all query operations through this interface instead.

    Select-only methods (setMaxResults, setCacheable, etc.) are no-ops by default; SelectQueryDelegate overrides them. Mutation-only operations (executeUpdate) throw java.lang.UnsupportedOperationException in SelectQueryDelegate and vice-versa for list() in MutationQueryDelegate.
