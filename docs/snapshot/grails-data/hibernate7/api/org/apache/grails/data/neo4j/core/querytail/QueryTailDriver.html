Package: org.apache.grails.data.neo4j.core.querytail

[Groovy] Class QueryTailDriver

    • org.apache.grails.data.neo4j.core.querytail.QueryTailDriver
    • All Implemented Interfaces and Traits:
      Driver
      @groovy.transform.CompileStatic
class QueryTailDriver
extends java.lang.Object
implements Driver

      The driver a Neo4j connection source hands GORM when query-tail capture is enabled: the driver the connection source built, with every session it opens recording the Cypher statements run on it, in a transaction or outside one, to the QueryTailCapture of the application before they are sent. A statement is recorded without its values, in the syntax of Cypher, and its parameters are never recorded; the statement runs unchanged. The capture opens with the first statement and closes when the driver closes, so a datastore that closes leaves nothing open, and one that fails to start before it ran a statement leaves the capture file as it found it.

      Statements run through the driver's asynchronous and reactive sessions are not recorded; GORM runs none.

      Nothing of this is installed unless QueryTailSettings.SETTING_ENABLED is set, so an application that does not capture pays nothing per statement.
