Package: org.apache.grails.datamapping.core.querytail

[Groovy] Class QueryTailRecorder

    • org.apache.grails.datamapping.core.querytail.QueryTailRecorder
    • All Implemented Interfaces and Traits:
      java.io.Serializable
      @groovy.transform.CompileStatic
class QueryTailRecorder
extends java.lang.Object
implements java.io.Serializable

      The capture of one connection source whose owner cannot open it up front, such as a session factory that is told it was created only after its first statements may have run, or a MongoDB client built before it is known whether a datastore will use it: the capture is opened by whichever comes first, the first statement recorded or open(), and closed once, with what owns it. A recorder closed before it opened never opens, so one that is built and let go unused leaves the capture file as it found it.

      The recorder travels with what owns it, which may be serialized, as a Hibernate session factory observer is; the capture does not. A recorder read back in the JVM that wrote it is the recorder written, so that what is recorded through either goes to the one capture its owner closes; read back anywhere else, or once the recorder written has closed, it records nothing, since nothing would close a capture it opened.
