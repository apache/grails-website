Package org.apache.grails.datamapping.core.querytail

  • Interface Summary 
    Interface Description
    QueryTailSyntax The lexical syntax of a database, as far as finding the values and the comments of a statement goes: where a string, a number, a quoted name or a comment that starts at a given index ends.
  • Class Summary 
    Class Description
    QueryTailCapture Writes the statements an application runs to the capture file the query-tail command tails.
    QueryTailCheckpoint Lets a process that captures statements be checkpointed with CRaC, which refuses to checkpoint a process that holds a file open: before the checkpoint every QueryTailCapture file is closed, along with its lock file, and after the restore each is opened again, as a capture opening it first would open it.
    QueryTailDialects The syntax the statements of a Hibernate session factory are redacted in, told by its dialect: that of the dialect's database, where the redactor knows the database's lexical rules.
    QueryTailJdbcConnection Records JDBC executions, including each entry submitted in a batch.
    QueryTailRecord One captured statement, SQL, Cypher, a MongoDB command or an operation of the simple datastore: when it ran, which data source ran it, the web request it belongs to and the page (controller and action) that request was serving.
    QueryTailRecorder The capture of one connection source whose owner cannot open it up front, such as a session factory that is told it was created only after its first statements may have run, or a MongoDB client built before it is known whether a datastore will use it: the capture is opened by whichever comes first, the first statement recorded or open(), and closed once, with what owns it.
    QueryTailRedactor Takes the values out of a statement before it is captured.
    QueryTailRequestAttribution Attributes a captured statement to the web request on the current thread.
