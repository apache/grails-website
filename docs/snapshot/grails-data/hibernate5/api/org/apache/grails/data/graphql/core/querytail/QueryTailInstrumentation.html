Package: org.apache.grails.data.graphql.core.querytail

[Groovy] Class QueryTailInstrumentation

      • org.apache.grails.data.graphql.core.querytail.QueryTailInstrumentation 
      • @groovy.transform.CompileStatic
class QueryTailInstrumentation
extends graphql.execution.instrumentation.SimplePerformantInstrumentation

        Counts the statements each GraphQL operation runs under the operation, for the query-tail capture. A GraphQL endpoint serves every operation on one page, as the GORM GraphQL plugin serves them on graphql/index; with this instrumentation the statements a request runs while an operation executes are counted under the page with the operation after it: graphql/index (query BookList). An operation is named by its type and the name its document gives it, or, when the document gives it none, by its type and the fields it selects at the top, which the schema defines, as query {bookList, authorCount}; an argument, an alias or a variable of the operation is never part of it. Only an operation that is valid against the schema executes, so every field named is one of the schema.

        The operation counts from the moment it starts executing until it completes, on whichever thread it completes, so that every statement its data fetchers run on the thread of the request counts under it, including those that load an association as its fields are read. A statement run on another thread, as a fetcher that returns its data later may run one, counts under that thread, as any work outside a request does.

        The GORM GraphQL plugin adds this instrumentation to the GraphQL it builds when capture is enabled with grails.gorm.queryTail.enabled; a GraphQL an application builds itself can be given it with install(GraphQL).
