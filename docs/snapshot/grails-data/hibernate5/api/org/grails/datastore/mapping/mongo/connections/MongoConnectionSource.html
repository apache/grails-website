Package: org.grails.datastore.mapping.mongo.connections

[Groovy] Class MongoConnectionSource

      • org.grails.datastore.mapping.mongo.connections.MongoConnectionSource 
      • @groovy.transform.CompileStatic
@groovy.util.logging.Slf4j
class MongoConnectionSource
extends DefaultConnectionSource<com.mongodb.client.MongoClient, MongoConnectionSourceSettings>

        The connection source MongoConnectionSourceFactory creates, whose com.mongodb.client.MongoClient can be replaced.

        A closed MongoClient cannot be reopened, so a datastore that closes its clients when it is stopped for a checkpoint builds new ones when it is started again after the restore. Putting each replacement here, where the original was, means that anything reading the client from the connection source rather than from the datastore gets the one in use, and that closing the connection source closes it when it is GORM's to close.

        It also owns the query-tail listener registered on its client when its settings enable capture: the listener is created and registered as the client is built (create), goes with the client wherever the client goes (adopt, replaceWith), and is closed with the connection source, or as soon as its client is handed out to whoever builds it for themselves (detach), since nothing would close a capture of it then.

          • void replaceWith(ConnectionSource<com.mongodb.client.MongoClient, MongoConnectionSourceSettings> built, MongoMappedFields fields)

            Replaces the client with that of a connection source a factory built from the same settings, after this one's was closed, and the query-tail listener with the one registered on it. The new listener is given the mapping of the datastore and opens its capture before the old one closes, so that it joins the run the old one writes. A replacement built without the listener, as a factory that builds its client other than through create builds it, records nothing, which is reported, as it is when such a factory builds the client a datastore starts with. The client being replaced is not closed here.

            Parameters:
            built - the connection source a factory built in place of this one
            fields - the fields the mapping of the datastore the connection source belongs to knows
            Since:
            9.0
