implements org.codehaus.groovy.transform.ASTTransformation, org.codehaus.groovy.transform.TransformWithPriority

      Global version of GormQuerySafetyTransformer - runs automatically against every class in every Grails application that has grails-datamapping-core on its compile classpath, with no developer configuration required.

      Since this check is intraprocedural and does not cover every possible way query text can be built (see GormQuerySafetyTransformer's documented limitations), a build that hits a false positive it can't otherwise work around may need to disable it entirely rather than per call site. Setting the {

      value:
      #PROTECT_SQL_INJECTION_ATTACKS_PROPERTY} system property to false skips this transformation for the whole compilation unit - this is a global kill switch of last resort, not a substitute for GormQuerySafetyTransformer.SUPPRESS_WARNINGS_VALUE.

      8.0

          System property that enables this check; defaults to true. There is no fully accurate way to guarantee protection against SQL/HQL/Cypher injection at compile time (this check has documented gaps), so the name describes intent, not a guarantee. Set to false only as a last resort, e.g. a false positive blocking a build with no other workaround.
