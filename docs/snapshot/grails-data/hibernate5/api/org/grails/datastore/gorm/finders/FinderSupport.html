Package: org.grails.datastore.gorm.finders

[Java] Class FinderSupport

    • org.grails.datastore.gorm.finders.FinderSupport 
    • public final class FinderSupport
extends java.lang.Object

      Shared session-execution helper for the synchronous finder implementations in this package. Not a base class - each finder holds a DatastoreResolver field and calls these statically, rather than inheriting an execute method. The datastore is resolved on every call, so a finder built from a lazy resolver follows whatever datastore the resolver returns at invocation time.
