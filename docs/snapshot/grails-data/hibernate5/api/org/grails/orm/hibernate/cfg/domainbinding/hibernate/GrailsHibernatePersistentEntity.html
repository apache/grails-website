          • public java.util.List<org.hibernate.mapping.Column> getReferencedIdentifierColumns(java.lang.String[] propertyNames)

            Returns the identifier columns for the given propertyNames in the order that aligns with the sorted foreign-key layout produced by sortOrIndexForeignKeyColumns.

            When the identifier is a org.hibernate.mapping.Component, columns are gathered per property name and then reordered according to the same permutation used during org.hibernate.mapping.Component#sortProperties(). When the identifier is a plain org.hibernate.mapping.KeyValue, its columns are returned directly.

            Parameters:
            propertyNames - composite identity property names in the caller's declared order
            Returns:
            identifier columns aligned with the foreign-key column layout, or an empty list if this entity has no persistent class or identifier

            Sorts or indexes the columns of value to align with this entity's composite identifier order. When the identifier is a org.hibernate.mapping.Component with an established sort order, delegates to org.hibernate.mapping.SimpleValue#sortColumns(int[]). Otherwise assigns sequential org.hibernate.mapping.Column#setTypeIndex(int) values so Hibernate can correlate them.

            Parameters:
