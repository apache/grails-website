Package: org.grails.orm.hibernate.persister

[Java] Class JoinTableCollectionPersister

        • org.grails.orm.hibernate.persister.JoinTableCollectionPersister 
        • public class JoinTableCollectionPersister
extends org.hibernate.persister.collection.BasicCollectionPersister

          The persister of a collection of entities in a join table that deletes the row of one removed element by the owner's key and the element's foreign key.

          Hibernate deletes a row of a set or a bag by the key and only the element columns that are not nullable. GORM leaves the element column of a join table nullable, and it has to where several collections share the table with a column each, so removing one element would delete every row of the owner's collection. A row of a collection of entities always has its element, so this persister restricts the delete by the element columns, nullable or not. GormPersisterClassResolver gives it to sets and bags of entities; lists and maps delete a row by their index.
