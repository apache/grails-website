Package: org.grails.orm.hibernate.query

[Java] Interface QueryPathContext

  • public interface QueryPathContext

    What a criterion or order handler sees of the query it converts for: the root of the query and the resolution of property paths the way the built-in criteria resolve them. alias.property, for an alias created with createAlias, or association.property becomes a path on the join GORM created for that association, so a custom criterion and a built-in one on the same association restrict the same row rather than each joining the association again.

    Since:
    8.1

        Resolves a path the way the built-in criteria resolve the property of a restriction, so a restriction on height restricts the property whatever a projection is called.
