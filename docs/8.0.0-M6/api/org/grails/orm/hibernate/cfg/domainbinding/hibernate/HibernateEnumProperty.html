[Java] Interface HibernateEnumProperty

      • org.grails.datastore.mapping.model.PersistentProperty
      • All Superinterfaces:
        HibernatePersistentProperty, PersistentProperty
        public interface HibernateEnumProperty
extends HibernatePersistentProperty

        Contract for Hibernate persistent properties that bind an enum value — either the property's own type or a basic collection's element type.

        Three concrete subtypes exist, corresponding to the three creation paths in HibernateMappingFactory:

        • HibernateSimpleEnumProperty — plain enum with no custom type marshaller
        • HibernateCustomEnumProperty — enum backed by a custom type marshaller
        • HibernateBasicEnumProperty — enum element of a hasMany basic collection

        Use instanceof HibernateEnumProperty instead of isEnumType() to branch on enum properties at binding time. Each implementation resolves its own enum class and column name so EnumTypeBinder can bind any of them through a single code path.
