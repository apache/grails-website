Package: org.apache.grails.core.plugins

[Java] Interface PluginDiscovery

  • public interface PluginDiscovery

    Defines a strategy for discovering the Grails plugins that should participate in application bootstrap.

    A PluginDiscovery implementation is initialized early in the application lifecycle, typically from GrailsEnvironmentPostProcessor, and later reused by the plugin manager and other bootstrap components. Implementations are expected to discover candidate plugins, apply filtering, resolve ordering, and expose the resulting plugin metadata through the methods in this interface.

    7.1
