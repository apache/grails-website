Package: org.grails.openapi.springdoc

[Groovy] Class SpringdocSelection

      • org.grails.openapi.springdoc.SpringdocSelection
      • All Implemented Interfaces and Traits:
        ActionHooks
        @CompileStatic
class SpringdocSelection
extends OpenApiSelection
implements ActionHooks

        What a document springdoc serves selects: its criteria, and the method filters and operation customizers springdoc applies to its handler methods, applied to the Grails actions too.

        A filter or customizer that fails, such as one that reads the current request where there is none, is skipped and logged, rather than the action it was applied to.
