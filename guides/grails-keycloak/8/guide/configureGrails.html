3 Configure the Grails Application

Add the Spring Security client libraries to build.gradle. Grails 8.0.0 manages the Spring Boot 4.1.1 line through grails-bom, so these two dependencies do not need their own versions:

implementation 'org.springframework.boot:spring-boot-starter-security'
implementation 'org.springframework.boot:spring-boot-starter-oauth2-client'

complete/gradle.properties sets grailsVersion=8.0.0. Keep initial/gradle.properties on that same version.

application.yml

The datasource stays on embedded H2. The Keycloak registration is the keycloak client under Spring Security’s OAuth2 client properties. The registration id is the last segment of the login callback, /login/oauth2/code/keycloak.

info:
  app:
    name: '@info.app.name@'
    version: '@info.app.version@'
    grailsVersion: '@info.app.grailsVersion@'
dataSource:
  driverClassName: org.h2.Driver
  username: sa
  password: ''
  pooled: true
  jmxExport: true
environments:
  development:
    dataSource:
      dbCreate: create-drop
      url: jdbc:h2:mem:devDb;LOCK_TIMEOUT=10000;DB_CLOSE_ON_EXIT=FALSE
  test:
    dataSource:
      dbCreate: update
      url: jdbc:h2:mem:testDb;LOCK_TIMEOUT=10000;DB_CLOSE_ON_EXIT=FALSE
  production:
    dataSource:
      dbCreate: none
      url: jdbc:h2:./prodDb;LOCK_TIMEOUT=10000;DB_CLOSE_ON_EXIT=FALSE
hibernate:
  cache:
    queries: false
    use_second_level_cache: false
    use_query_cache: false
grails:
  codegen:
    defaultPackage: com.grails.example
  profile: web
  views:
    gsp:
      encoding: UTF-8
      htmlcodec: xml
      codecs:
        scriptlet: html
spring:
  security:
    oauth2:
      client:
        registration:
          keycloak:
            provider: keycloak
            client-id: ${KEYCLOAK_CLIENT_ID}
            client-secret: ${KEYCLOAK_CLIENT_SECRET}
            authorization-grant-type: authorization_code
            redirect-uri: "{baseUrl}/login/oauth2/code/{registrationId}"
            scope:
              - openid
              - profile
              - email
        provider:
          keycloak:
            issuer-uri: ${KEYCLOAK_ISSUER}

KEYCLOAK_ISSUER is the realm issuer, http://localhost:8081/realms/example, not the Keycloak root URL.

Register the role mapper

KeycloakAuthoritiesMapper is not a Spring stereotype. Register it in grails-app/conf/spring/resources.groovy so SecurityConfig can inject it:

import com.grails.example.KeycloakAuthoritiesMapper

// Place your Spring DSL code here
beans = {
    keycloakAuthoritiesMapper(KeycloakAuthoritiesMapper)
}

Place SecurityConfig and KeycloakAuthoritiesMapper in src/main/groovy/com/grails/example/. Place SecurityTagLib in grails-app/taglib/com/grails/example/. The next chapter walks through each class.
