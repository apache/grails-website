3.5 Use the Taglib

Use Trix in create and edit GSPs. Those were generated with the static scaffolding generate-all command.

Replace:

<f:all bean="announcement"/>

with:

/grails-app/views/announcement/create.gsp
link:../snippets/grails-app/views/announcement/create.gsp[role=include]
/grails-app/views/announcement/edit.gsp
link:../snippets/grails-app/views/announcement/edit.gsp[role=include]
