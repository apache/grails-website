# Contributing to Grails

Thank you for considering contributing! ❤️

Grails is an open-source project with a vibrant community, and we rely on contributions from people like you to make it even better. 
There are many ways to get involved, whether it’s fixing bugs, proposing new features, improving documentation, or giving feedback. Every bit of help is valuable, and we really appreciate your time!

We encourage all kinds of contributions. Check out the Table of Contents
 to see how you can get involved and understand how we handle contributions. Reading the relevant section before submitting your work will make the process smoother for everyone. 
 The community is excited to collaborate with you! 🎉

> If you like the project, but just don't have time to contribute, that's fine. There are other easy ways to support the project and show your appreciation, which we would also be very happy about:
> - Star the repository
> - Talk about it on Social Media
> - Refer to this project in your project's readme
> - Mention it in your own projects or blog posts
> - Join our community channels and help others

## Got a Question

> Before asking, we recommend: [Documentation](https://grails.apache.org/docs/latest/).

Before you ask a question, it is best to search for existing [Issues](https://github.com/apache/grails-core/issues) that might help you. In case you have found a suitable issue and still need clarification, you can write your question in this issue. It is also advisable to search the internet for answers first.

If you then still feel the need to ask a question and need clarification, we recommend the following:

- Ask a question on [Stack Overflow](https://stackoverflow.com/questions/tagged/grails).
- Join the community chat on [Slack](https://grails.slack.com).
- If your question is about a bug, open a new [Issue](https://github.com/apache/grails-core/issues/new).
  - Provide as much context as possible.
  - Include project and environment details (OS, Grails version, dependencies, etc.)
  - Include any relevant code snippets or steps to reproduce the issue
